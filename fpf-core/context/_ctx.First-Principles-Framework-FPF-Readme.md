# First Principles Framework (FPF) Readme

The [Library’s document identities and current carriers (Library.Reference:11.1)](https://github.com/ailev/FPF/blob/main/FPF-LIBRARY-REFERENCE.md#libraryreference111---document-identities-and-current-carriers) identify complete publications by DocID and full title. For a citation that must work beyond its present hyperlink, keep the full PatternID or SectionRef and enough context to identify the document. Add a document qualifier only if the document would otherwise be unclear.

> First Principles Framework (FPF) is a standards-style pattern language for making reasoning in difficult engineering, research, management, and mixed human and AI work explicit, reviewable, and improvable.

FPF is useful when meanings, claims, options, evidence, architecture, work decisions, publication forms, and improvement criteria need to stay coherent across people, teams, tools, time, or AI agents.
