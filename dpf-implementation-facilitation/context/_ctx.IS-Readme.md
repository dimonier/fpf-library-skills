# IS.Readme - Find the first useful contribution

Implementation Facilitation helps practitioners, organizations and affected people make an evidence-informed practice usable in its setting and develop their ability to conduct subsequent changes. Enter at the missing contribution; a sufficient local answer can be enough. The examples below show ordinary entries. Use the [pattern index](#table-of-contents) for a different question.

**A tool is available but cannot be used.** A practitioner tries to compare two source editions and discovers that the older one cannot be opened. Start with IS.2. Recover the failed input and obtain the source owner's access result. If that makes the already understood operation possible, the useful answer can stop there. If the source does not exist, return the target operation to its subject owner.

**A sponsor asks for training while ordinary work makes the practice costly.** Start with IS.1 to distinguish the recipient result from the requested activity. IS.2 then follows a real episode: is an operation missing, or are people capable but unable to obtain time, permission or a workable response to their findings? Obtain the appropriate contribution. A learning programme belongs with HCD when personal acquisition is needed; organizational decisions belong with their actual authority and OCE.

**Participants disagree about a practice that works for some and excludes others.** Start with IS.6 when the people who experience the difficulty cannot affect the decision. Use IS.7 to act on the interaction between the practice, those using or receiving it, and its setting. This may require a change in the proposed practice, in the facilitating help, or in a condition controlled elsewhere. If recipients are expected to conduct later changes themselves, IS.8 develops that ability through actual facilitation work and evidence of what they can subsequently do.

**Temporary help is ending.** Start with IS.5 using what the work already shows. Identify which contribution must continue, who can supply it and what unfinished work remains. Retain adequate current provision, arrange an actual transfer or end the contribution responsibly. Reopen strategy construction through IS.3 only where the continuation needs it.

The [Architectural Reference](#isreference1---implementation-facilitation-and-the-language-that-describes-it) explains the connected practice and its distinctions. The pattern bodies develop the Methods and worked cases.
